## Files

- `login2.html` - Alternative design/version.
- `login3.html` - Alternative design/version.
- `logo.jpeg` - Logo displayed in the page and README.
- `photo-1542838132-92c53300491e.jpg` - Background image used by the page.
- `newwww.jpg` - Additional visual asset.

## GitHub Pages

Use these settings:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

## Notes

This is a static HTML/CSS/JavaScript project. GitHub Pages can display the pages directly, but any real authentication backend must be hosted separately.
